# Chutzpah VPN operations

Репозиторий содержит обезличенную документацию по эксплуатации VPN-сервера и журнал работ. Он **не содержит** конфигурацию панели, клиентские профили или секреты.

## Текущая схема

- Ubuntu Server 24.04 LTS.
- 3x-ui управляет Xray; Xray 26.7.28.
- VLESS + TCP + REALITY: основной новый вход на TCP/443; старый резервный вход пока остаётся на TCP/19744.
- Caddy обслуживает веб-панель на TCP/8443 и HTTP-01 для TLS-сертификата на TCP/80.
- UFW разрешает TCP/22, 80, 443, 8443 и 19744 (IPv4 и IPv6).
- Включены Fail2ban, автоматические обновления безопасности и запуск сервисов при загрузке.
- SSH для root настроен на вход по ключу; парольная аутентификация отключена.

Инфраструктура намеренно не привязана в документации к IP-адресу, домену или URL панели: репозиторий публичный.

## Важные незакрытые пункты

1. Подтвердить подключение клиентского профиля через TCP/443 на реальном устройстве.
2. После миграции всех клиентов отключить резервный вход на TCP/19744 и закрыть этот порт в UFW.
3. Запланировать перезагрузку сервера: система сообщает о необходимости reboot после обновления `libc6`. Перезагрузка прервёт VPN на время запуска.
4. Ограничить доступ к панели по исходному IP или через VPN, если это совместимо с процессом администрирования.

## Правила для репозитория

- Не добавлять сюда `/etc/x-ui`, базу SQLite панели, конфиги Xray/Caddy/SSH/UFW, приватные ключи, парольные файлы, UUID, subscription links, QR-коды и клиентские профили.
- Секреты хранить в менеджере секретов или в файлах с ограниченными правами доступа вне Git.
- Перед коммитом просматривать `git status` и полный diff. `.gitignore` снижает риск, но не заменяет проверку содержимого и истории.
- Этот репозиторий документирует установленную систему; он не является исходным кодом 3x-ui или Xray и не выполняет автоматический деплой.
